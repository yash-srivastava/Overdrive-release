Privacy and runtime
  • The API key uses the same device-bound encrypted storage path as BYD Cloud credentials and is never returned to this page.
  • Chat history stays only in this WebView's memory and is cleared when the page closes or reloads.
  • Vehicle context is sent only for an explicit grounded action. Context is treated as data, never as provider instructions.
  • Starting voice opens a provider-native realtime session through the daemon. It closes when stopped, when this page leaves the foreground, or after inactivity.
  • When the master switch is off, active calls are cancelled and the provider connection pool and dispatcher are destroyed.
  • Requests re-evaluate the OverDrive proxy route each time. If a Tailscale proxy is expected but unavailable, the request fails closed instead of dialing directly.
