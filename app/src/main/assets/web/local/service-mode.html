Service Mode

Temporarily hide selected third-party apps and the OverDrive launcher entry during a dealer visit. The daemon remains running and restores the saved states automatically at the end of the selected date.

Checking Service Mode…
Reading the current device state.

    Schedule automatic restoration

    Service Mode starts immediately. The selected apps and features are restored at 23:59:59 on the chosen date in the head unit's local time zone, or sooner when you end it manually.

    Launcher visibility

    OverDrive stays installed. Only its dedicated launcher alias is hidden, leaving the daemon, boot receivers and local WebUI available for restoration.

    Third-party apps

    Choose installed user apps to hide temporarily. Android and BYD system apps, home launchers, enabled keyboards and OverDrive are excluded.

    Only eligible launchable apps are listed.

    Pause OverDrive features

    These runtime gates do not delete or modify your saved rules, bindings or configuration.

    Only select apps you are comfortable disabling temporarily. Do not select apps required for vehicle controls or diagnostics. Apps that were already disabled before Service Mode are not enabled when Service Mode ends. If a package is reclassified as a system app while the mode is active, it will not be disabled again during reconciliation.
