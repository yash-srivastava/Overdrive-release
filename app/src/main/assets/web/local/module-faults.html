Read-only overview of vehicle warnings currently exposed by BYD telemetry.

Partial diagnostic coverage

This first version reads existing TPMS, 12V battery and charging-state indicators. It does not read stored ECU diagnostic trouble codes (DTCs), and it does not send CAN/UDS commands, clear faults, reset modules or change vehicle settings.
