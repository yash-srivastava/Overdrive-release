The car will leave WiFi
This head unit has one WiFi radio, so it cannot host a hotspot and stay on a WiFi network at the same time. While the hotspot is on, the car disconnects from WiFi and uses the built-in SIM's mobile data for itself and for every connected device. WiFi comes back when you turn the hotspot off.
Share mobile data over WiFi
Turns the head unit into a WiFi access point that shares the built-in SIM's internet.

Proxy
Route this car's traffic through the proxy
Sets the system-wide HTTP proxy so apps on the head unit use the encrypted tunnel. Needs the proxy service running.
Give connected devices internet (proxy)
Connecting to the hotspot is not enough — this vehicle can't route devices to the internet on its own, so each device must be pointed at the car's proxy. On the device, after joining this hotspot: 1) open its Wi-Fi settings and edit this network, 2) set Proxy to Manual, 3) enter the hostname and port shown here, 4) save, then browse. The device keeps showing "no internet" and its own mobile-data icon even when this is working — that check ignores proxies.
Also encrypt connected devices' traffic
Sends connected devices' traffic through the encrypted tunnel before it leaves the car's SIM. Point devices at port 8122 instead of 8121. Slower, since it adds a hop. Turning this off stops that port listening immediately.
